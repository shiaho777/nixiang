## 二、排名机制 (完全破解 + 实验验证)

### 排序公式
```
总分 = 桶(bucket) + 版本惩罚(+0 或 +20)
```
1. 先按总分升序
2. **总分相同时，按 `game_map` (CSV 第9列) 的 Java 字符串字典序升序**
3. **game_map 也相同时，Java stable sort 保留 CSV 原始顺序**

> ⚠️ tiebreaker 是 `game_map`，不是 `created_by`！
> 通过 androguard 字节码逆向 r.java 确认:
> `aget-object v17, array, 9` → `iput-object v17, fVar.q`

### 桶分配 (gh.java method a 字节码验证)
```
桶 0: IP 以 "url:" 开头 (仅开发者 Discord 链接，不可达)
桶 1: flag_x=true 且 status="chat"
桶 2: f.a=true (beta 字段)  ← 理论上存在，但实际被 m.c() 覆盖为 false
桶 3: flag_x=true, battleroom, 有空位, players>0  ← 🎯 目标桶 (所有远程服务器)
桶 4: flag_x=true, battleroom, 有空位, players=0 (空房)
桶 5: flag_x=true, ingame
桶 6: flag_x=true, battleroom, 满员
桶 7: 有密码, flag_x=false, 有空位
桶 8: 有密码, flag_x=false, 满员
桶 9: 其他
```

### 版本惩罚 (method b 字节码验证)
- `game_version=176` 且客户端也是 176 → 匹配 → 无惩罚 ✅
- 不匹配 → +20（排到很后面）
- 特殊: version_string="ANY" 或含 "+" 时可跨版本兼容

### ⚠️ f.a (beta) 不影响排名的根因
**gh.java 字节码确实有 beta→桶2 的判断**:
```
[14] iget-boolean v0, v2, f;->a Z
[15] if-eqz v0, +004h
[16] const/4 v0, 2          ← return 2
```
**但 `m.c()` (findOrCreateServer) 初始化 f 对象时强制 `f.a = false`**:
```
[13] const/4 v1, 0
[14] iput-boolean v1, v0, f;->a Z  ← f.a = false (覆盖!)
```
虽然 r.java [257] 会用 `parseBoolean(CSV[13])` 赋值 f.a，但在缓存命中时 m.c() 直接返回已有对象（f.a=false），**跳过了 r.java 的赋值**。结果：所有远程服务器的 f.a=false，beta→桶2 永不生效。

### 排名第一的关键

|------|------|------|
| **game_map** | `""` (空字符串) | 空排最前面，赵云也是空的 |
| **flag_x (cols[19])** | 必须 `true` | 否则不进桶3 |
| **public** | 必须 `true` | VPS 蜜罐通过端口检查 |
| **status** | `battleroom` | 桶3条件 |
| **player_count** | `> 0` (如 7) | 否则进桶4 |
| **players < max_players** | 有空位 | 否则进桶6 |
| **game_version** | `176` | 避免+20惩罚 |
| **password** | `false` | 否则进桶7/8 |

## 八、加密函数

```python
import hashlib

def java_md5(s):
    return hashlib.md5(s.encode('utf-8')).hexdigest()

def f_d(s):
    """SHA-256 前4位大写hex (bf.java 验证参数)"""
    b = hashlib.sha256(s.encode('utf-8')).digest()
    n = int.from_bytes(b, byteorder='big', signed=False)
    return format(n, '064X')[:4]

def rw_hash_14(s):
    """SHA-256 前14位大写hex (Relay integrity challenge)"""
    return hashlib.sha256(s.encode()).hexdigest().upper()[:14]
```

## 十、逆向过程中的关键教训

1. **jadx 反编译不可靠** — r.java (849条指令) 反编译失败，导致我们错误地以为 tiebreaker 是 created_by
2. **androguard 字节码分析是最终武器** — 直接从 DEX 读取指令序列，确认了 fVar.q = CSV[9] = game_map
3. **用户截图是最好的真相** — 用户反馈"排名和名称无关"促使我们重新分析
4. **空字符串 game_map** — 赵云排名第一的真正秘密，不是什么楔形文字前缀
5. **beta=true 是红鲱鱼** — gh.java 有 beta→桶2 的代码，但 m.c() 覆盖了 f.a=false，导致该分支永不执行
6. **回归第一性原理** — 放弃所有假设，直接对比 CSV 数据，发现 CSV 原始顺序才是终极决定因素
7. **Master Server 安全性较高** — 逗号过滤、状态覆盖、beta 覆盖、IP 限流，基本堵死了客户端欺骗的路径
